# 项目结构说明

本项目按“可运行应用、工程实现、输入资源、研究文档、生成产物”分层。项目根目录只保留一键入口、Node.js 配置和 GitHub 识别的标准文件。

## 目录职责

| 目录 | 内容 | 修改方式 |
|---|---|---|
| `应用/前端` | 研究主界面、比赛模式、星神模式、浏览器端逻辑和图片素材 | 页面与浏览器逻辑可直接修改；`*-data.js` 多数由构建脚本生成 |
| `工程/源码` | 核心模型、搜索流程、模拟器、实验和审计 | 主要工程源码，修改后必须运行测试 |
| `工程/测试/样本` | 真实局面与永久回归样本 | 只追加可复现样本，不存临时调试数据 |
| `工程/工具` | LLM 本地代理、README 图表生成器 | 独立工具入口 |
| `工程/脚本` | 上游数据更新和批量重建 | 从项目根目录通过 npm 命令调用 |
| `资源/游戏数据` | 腾讯游戏资料快照、规则集、星神目录 | 上游快照不手工美化；版本规则必须保留证据来源 |
| `文档/研究报告` | 模型实验、机制审计和版本报告 | 人工结论与脚本生成报告均集中在这里 |
| `文档/阵容资料` | 官方阵容的结构化明细 | 由数据分析流程更新 |
| `文档/图片` | README 图表与界面说明图 | 研究图由 `npm run figures` 生成 |
| `生成产物/结果` | 模型输出 JSON | 不直接手改，由构建流程重建 |
| `生成产物/截图` | 浏览器验收截图 | 验收时更新 |
| `.local` | PID、端口、日志和本机 QA 临时文件 | 本机运行时自动产生，不提交 Git |

## 根目录文件

- `启动前端.command`：macOS 双击启动入口，自动使用自身所在项目目录。
- `package.json`：测试、构建、服务和数据更新命令的统一入口。
- `README.md`：项目说明、研究边界、快速开始和报告索引。
- `.github`、`LICENSE`、`NOTICE.md`、`SECURITY.md`、`CONTRIBUTING.md`、`CODE_OF_CONDUCT.md`：GitHub 和开源工程标准文件，因此保留标准名称。

## 常用命令

```bash
npm test                 # 完整确定性回归
npm run serve            # 启动静态前端
npm run build            # 重建全部模型与报告
npm run figures          # 重建 README 研究图
npm run update:data      # 更新上游游戏数据并重建
```

## 命名原则

用户直接浏览的分类、文档和启动入口使用中文。源码模块名、npm 命令、网页文件名和机器读取的 JSON 文件名保留通用英文，避免破坏模块导入、URL 稳定性、CI 与跨平台工具兼容性。
